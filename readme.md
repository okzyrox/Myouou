# Myouou

## Dependencies
- D (dmd 2.112+)
- Visual Studio w/ C++ Tools.
- CMake 3.12+
- Boost (any modern version mostly)
    - Follow the guide in `Externals/boost/boost.md` for installation
- SDL3 (3.4.20)
    - Newer (or older) versions may work, but I will only test with `3.4.20`
    - The SDL3 Libs for VC should be placed inside the `Bin` folder for linking.
- Any extra submodules listed in `Externals/`
